# AWS Cloud Engineer Portfolio

> A professional AWS Cloud Engineering portfolio documenting AWS services, architecture, security, networking, monitoring and production-style cloud projects.

## 🎯 Career Objective

This portfolio is focused on becoming an **AWS Cloud Engineer**.

The learning and portfolio sequence is:

```text
AWS Service Knowledge
        ↓
AWS GitHub Portfolio
        ↓
Production-Style AWS Projects
        ↓
AWS Job Applications
        ↓
AWS Interview Preparation
        ↓
AWS Cloud Engineer Job
        ↓
AWS DevOps (later)
```

## 🏗️ Portfolio Principles

Every AWS service is documented from a Cloud Engineer perspective:

- What the service is
- Why companies use it
- Core concepts
- Architecture
- Security
- Availability
- Monitoring
- Cost awareness
- Real-world use cases
- Interview questions
- Scenario-based questions

## 🔐 Security

No credentials, secrets, access keys, private keys, tokens or sensitive AWS information should ever be committed to this repository.
